Welcome to Lookout

Lookout builds a map of Street View locations that stand near one kind of place and face it: every lighthouse, windmill or castle with Street View nearby, for example. You then import the result into map-making.app.

  1. Choose what to look at. Type a kind of place and pick a suggestion. You can also give words the name must contain.
  2. Choose where. Tick one or two countries at a time. Searching all 119 countries with Street View at once is possible, but slow.
  3. Set how close and how many, then select "Find locations".
  4. Review and download. Check the locations on the map or under "List by name", remove the ones you don't want, then download the map file.
Expect to wait, and sometimes to try again. The places come from free OpenStreetMap servers that are often busy and slow. A search can take a minute or more, and it can run out of time without a result. When that happens, select "Try again". It can take several attempts.
Search one or two countries at a time. Searching all 119 Street View countries at once takes a long time and is likely to run out of time, except for rare kinds of place. In step 2, tick one or two countries, and run the search again for the next ones.

    Can't find it? Write a tag yourself

    Places come from OpenStreetMap, where every object carries labels called tags, written as key=value. The suggestions cover the common ones. Anything else can be typed straight into the field.

    historic=castleEverything tagged as a castle.
    amenity=pub|barEither value. Separate choices with |.
    historic=*Any value for that key.
    amenity=fast_food, brand=KFCBoth tags must be present. Separate with a comma.

    Looking for one specific thing

    Combine a kind of place with "Name contains". For replicas of the Statue of Liberty, choose "Artwork" and enter liberty, liberté, freiheitsstatue, libertad. Names are written in the local language, so add the spellings you expect.

    Finding the tag of a real place

    Open openstreetmap.org, right-click an example and choose "Query features". Pick the entry in the list and read its tags. Use the one that says what the thing is, not its name or address.

    m

    The search stops once this many locations are found. It is an upper limit, not a promise: if fewer places have Street View within range, you get all of those.

    • Every matching place is fetched from OpenStreetMap first, then checked in random order. You get a random selection, and running the search again gives a different one.
    • Locations are not spread evenly. Countries with more matching places get more locations.
    • To get every place, enter a number higher than the places found. The largest allowed is 100,000.
    • If you remove a location while the search is running, it looks for a replacement.

    Shorter distances give clearer views but fewer locations. Raise it for large buildings and grounds.

    Raise this for tall things that are hard to see from right underneath.

    Expert: the OpenStreetMap query, or your own result

    The query

    The Overpass query for the settings in steps 1 and 2. It updates as you change them. Results come grouped by country: each country's area is followed by its places. The page itself sends this query in several parts, a few countries at a time.

    Open in Overpass Turbo

    Use your own Overpass server

    If you have access to a paid or private Overpass server, enter its address here, including your key. Examples: https://tile.tracestrack.com/overpass/YOUR-KEY/ or https://overpass.geofabrik.de/YOUR-KEY/api/interpreter. The page tests the address before using it.

    The address contains your key. It stays in this browser, is sent only to that server, and is never put into a shared link.

    Use your own Overpass result

    Run any query in Overpass Turbo and load its result here. The page then skips its own OpenStreetMap search and only checks Street View near your places.

    Only one format is accepted: raw OSM data as JSON. In Overpass Turbo choose Export, then Data, then "raw OSM data". The query must start with [out:json] and should end with out center; so that outlines get a position. GeoJSON, GPX, KML and XML files are not accepted.

    Country codes and country tags are kept only if the query has the country grouping of the query above. The file is read in your browser and is not sent anywhere.
